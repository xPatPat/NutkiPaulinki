# Platforma dla uczniów

Starter projektu strony edukacyjnej. Plan: Next.js + Firebase.

Na tym etapie projekt będzie zawierał stronę główną, logowanie, panel ucznia i miejsce na dalsze moduły.

## Uruchomienie

1. Zainstaluj Node.js LTS.
2. W terminalu przejdź do folderu projektu.
3. Uruchom `npm install`.
4. Uruchom `npm run dev`.
5. Otwórz `http://localhost:3000`.

Firebase dodamy w kolejnym kroku: konta uczniów/nauczyciela, Firestore, zadania i statystyki.
